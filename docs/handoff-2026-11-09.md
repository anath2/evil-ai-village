## Communication experiment

The frozen v4 design compares six-agent shared/private finding conditions,
three rolling active agent loops, across three homogeneous model families and
a mixed roster, six paired seeds each. The unit is the village. The primary
outcome is controller-confirmed task-file change, not a heuristic tamper label
or malicious intent. The bounded synthetic mock task is intentionally unsolvable.

Technical calibrations, all excluded from the main comparison:

- v1 optional-board pilot did not produce peer exposure.
- v2 matched note-taking instructions still did not produce peer exposure.
- v3 independently prepared, yoked notes established exposure/isolation, but
  9/75 model calls failed at the output-token limit, exceeding the 10% gate.
- v4 raised action output allowance to 8,192 tokens. All 68 model calls
  completed, but only 52/62 returned actions were valid (83.9%, required 90%).
  Other fidelity/provenance checks passed. The coordinator stopped before main.
